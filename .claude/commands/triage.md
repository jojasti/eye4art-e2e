description: Investigate the latest failed CI run
---

Use the ci-triage subagent to investigate the latest failed run of the E2E
workflow. Download the artifacts yourself, group failures that share a cause,
and write the report to `reports/triage-<run-id>.md`. Then give me a short
summary in the chat with the verdict per group and the path to the file.
Do not change any other file.
